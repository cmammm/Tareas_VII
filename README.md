# Tareas_VII

<h1>Producción y comunicación en la cultura colaborativa - Camila Díaz Pavón</h1>

<h2>Objetivo del Repositorio</h2>
<p>Este repositorio existe para reunir todo el trabajo que desarrollé durante el séptimo trimestre en la UEA. Más que solo contener archivos, lo uso como un espacio para ordenar procesos, avances y materiales que fui generando a lo largo del curso. La idea es que funcione como una carpeta central donde se pueda ver claramente qué hice, cómo lo organicé y cómo fueron avanzando las actividades.<br>

El objetivo principal es tener un registro completo y accesible, no solo para la revisión académica, sino también para mí. Me ayuda a entender mejor mis propios procesos y a mantener un historial limpio de mis proyectos. Además, me permite documentar decisiones, experimentar con diferentes formas de estructurar contenido y mantener todo disponible en un solo lugar.<br>

También funciona como una forma de aplicar buenas prácticas que ya manejo: mantener claridad en los archivos, usar commits con intención y aprovechar GitHub como herramienta de organización.</p>

<h2>Organización del Repositorio</h2>
<p>La estructura del repositorio está pensada para que navegarlo sea sencillo. Lo organicé por carpetas que separan cada actividad o práctica que estamos vimos en la UEA.<br>

Trato de mantener nombres claros para evitar confusiones y así saber rápidamente qué corresponde a qué. También cuido que los archivos estén donde deben y que no haya duplicados o cosas innecesarias.<br>

La organización ayuda cuando toca regresar a una entrega o corregir algo: todo está ordenado y no tengo que buscar entre archivos sueltos. La idea principal es que tanto yo como cualquier persona que entre al repo pueda moverse sin perderse. En general, es una estructura práctica, limpia y pensada para que fluya el trabajo del trimestre.</p>

<h2>Experiencia Personal al Crear y Gestionar el Repositorio</h2>
<p>Trabajar con este repositorio fue una experiencia bastante "rapida" o simle, porque ya estoy acostumbrada a manejar mis proyectos en GitHub. Aun así, cada trimestre es diferente y siempre termino ajustando la manera en que organizo las cosas. En esta ocasión, me ayudó a mantener una rutina más ordenada y a llevar un control claro de mis avances.<br>

Aunque no fue un proceso nuevo, sí me sirvió para reafirmar lo importante que es tener buenos hábitos de documentación. Cosas como escribir mensajes de commit claros o mantener una estructura coherente hacen que todo sea más fácil cuando regreso a revisar o modificar algo. También disfruté poder ver cómo se iba armando el repositorio a lo largo del trimestre y cómo se iba llenando de contenido.<br>

En general, gestionar este repo fue útil para mantener el ritmo del curso, evitar perder archivos y tener siempre una referencia de lo que estaba trabajando. Más que un requisito, lo veo como una herramienta que me ayuda a mantener orden y claridad en mis proyectos académicos y personales.</p>
